### Featured Projects

#### 1. [All_in_One — Enterprise Agentic Commerce Platform](https://github.com/mahimalam/All_in_One)
> **Multi-tenant conversational commerce platform uniting social messaging channels and marketplaces with an autonomous, grounded AI sales agent.**
- **Stack**: `TypeScript` · `Next.js 15` · `PostgreSQL (RLS + pgvector)` · `Fastify` · `BullMQ / Redis` · `Meta Cloud API (WhatsApp)` · `TikTok Shop API`
- Enforces strict downward-only four-plane architecture with versioned contracts and cryptographic tenant data isolation.
- Grounded AI sales agent capable of catalog search, reactive order capture, triage, and multi-channel webhook processing.

#### 2. [CodeMate — Desktop AI Coding Workspace & Agent IDE](https://github.com/mahimalam/codemate)
> **Supervised desktop AI coding environment combining Monaco editor, sandboxed execution, and multi-model agent loops.**
- **Stack**: `TypeScript` · `React` · `Python` · `FastAPI` · `Electron` · `SQLite (WAL)` · `Bubblewrap`
- Network-isolated Linux Bubblewrap sandbox for bounded command execution, atomic file writes, and revision-aware AST patches.
- Provider-agnostic agent adapters supporting local models (Ollama) and cloud APIs (Claude, OpenAI) with persistent SQLite event journals.

#### 3. [Void — Voice-Activated AI Assistant & Second Brain](https://github.com/mahimalam/Void)
> **Always-listening desktop AI voice assistant with an autonomous cognitive memory engine and desktop automation.**
- **Stack**: `Python` · `LanceDB` · `FastAPI` · `Speech & Audio Pipelines` · `Knowledge Graph`
- Deep persistent Second Brain using semantic vector retrieval and knowledge graph activation to retain context across sessions with zero memory loss.
- Zero paid subscription requirements: supports high-performance local and free-tier cloud model execution.

#### 4. [FIFA World Cup 2026 Forecasting & Analytics Engine](https://github.com/mahimalam/llm-sports-forecasting-engine)
> **High-performance sports forecasting engine with quantitative Poisson models, real-time match tracking, and Telegram Mini-App (TMA).**
- **Stack**: `Python 3.12` · `FastAPI` · `Astro 4` · `React 18` · `Telegram Mini-App` · `Cloudflare`
- Mathematical Poisson distribution engine calculating win/draw probabilities and expected scores across all 104 matches.
- Low-latency live score polling failovers and programmatically generated static pages for 48 national teams and group standings.
